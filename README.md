# DEADPOOL: BREAK THE CODE

A cinematic Marvel-inspired event landing page for the
GeeksForGeeks Student Chapter, Bennett University.

## Concept

The website presents the event as a Deadpool-style mission
that has "hijacked" the GFG event interface.

The design combines:
- Deadpool-inspired red and black visual language
- Cinematic typography
- HUD/interface elements
- Glitch transitions
- Fourth-wall humor
- Interactive registration experience

## Features

- Cinematic opening animation
- Responsive landing page
- Smooth navigation
- Interactive sections
- Countdown
- Registration modal
- Form validation
- Responsive mobile experience
- Reduced-motion support
